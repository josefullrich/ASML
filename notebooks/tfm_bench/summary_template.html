Reliability by amount of context (pooled over datasets)

One panel per context arm; the GPs (dashed) never use context, so they are the same reference in every panel. Closer to the diagonal is better. Above it on the left and below on the right = too confident; the reverse = too cautious; entirely above/below = biased. Legend numbers = mean |gap| to the diagonal, best first.

Coverage & width quality by amount of context

Top: observed coverage of each model's central intervals at 10–99% (diagonal = honest). Bottom: width ratio = actual width ÷ the width this model needed for its own errors (log scale). 1 = exactly right; above 1 = wider than necessary; below 1 = too narrow. A model with big errors and big intervals sits at 1 — it is not punished for being wide, only for being wrongly wide or narrow. Legend numbers: coverage panels = mean |coverage − nominal|; width panels = width error (mean |log₂ ratio|; 1 = off by 2×). Uses the Whole run / Last 20% tab above.
